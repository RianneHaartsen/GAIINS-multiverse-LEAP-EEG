# GAIINS-multiverse-LEAP-EEG
These MATLAB scripts were used to create the multiverse and follow up analyses presented in the manuscript entitled ‘An EEG multiverse map for individualised research in developmental neuroscience’. The scripts take pre-processed EEG data from the FaceERP task and social and non-social videos collected as part of the LEAP wave 1 dataset. 

The script Multiverse_1_CreatingMultiverseSpace.m takes the pre-processed data and takes half of the sample of subjects. It then normalises the data for the multiverse space. The multiverse space is created using the MATLAB function cmdscale on the Spearman distance matrix of the normalised data. The remainder of the script includes code to visualise the multiverse. 

To validate the multiverse space, we modelled individual responses of brain metrics across the space and compared these modelled values to the observed individual responses. The script Multiverse_2_ValidatingMultiverseSpace.m contains the code for this approach. It takes the other half of the sample that was not used to create the multiverse on. Data were normalised using the parameters from the sample that the multiverse was created with. Individual responses were modelled with the MATLAB Gaussian Process Regression fitgrp for the 2D and 3D space, and with metrics across tasks and out-of-task metrics (e.g. predicting FaceERP EEG metrics from social and non-social video EEG metrics). 

In further analyses, we wondered whether the model performance was related to other factors, such as data quantity, age, IQ, or clinical measures. These analyses are in the script Multiverse_3_ModelPerformanceWVariables.m. We calculated the associations between model performance (operationalised as the correlation between the model predicted EEG metrics and the observed EEG metrics) and the other factors. The script contains these analyses for the whole group and split by sites, sex, and diagnostic groups to check for effects. 

Finally, we explored whether there were topological associations in the multiverse. Script Multiverse_4_AssociationsAcrossMultiverse.m calculates the correlation between other factors and each EEG metric and plots these correlations into the multiverse space for visual inspection of the associations. These topographical associations are generated and plotted for age, IQ (VIQ, PIQ, and FSIQ), and behavioural measures of daily living skills, autistic traits, and sensory sensitivities. These are examined for both subsamples (sample to create the space and sample to validate the space) and for groups split up by sex, site, and diagnosis (only for subsamples with 15 participants or more). This script also calls to the function multiverse_associations_across_space.m which generates the plots for the different subsamples (reported in the supplementary information of the publication). 

The script entitled Multiverse_5_Figures.m contains the code to generate the figures in the main manuscript. They call onto the data generated by the other scripts in this repository.
